# 🚀 Website Audit Pro AI

Website Audit Pro AI is a modern web-based auditing tool that analyzes website health, SEO readiness, performance metrics, security indicators, and accessibility factors. It provides detailed audit reports, issue detection, recommendations, and export options through a clean SaaS-style dashboard.

## ✨ Features

* Website URL Analysis
* SEO Score
* Performance Score
* Security Score
* Accessibility Score
* Website Health Check
* Issue Detection
* Smart Recommendations
* JSON Export
* CSV Export
* Dark / Light Mode
* Responsive Design
* Modern SaaS Dashboard

## 🚀 How To Use

1. Enter a website URL.
2. Click "Start Audit".
3. Wait for the audit process to complete.
4. Review scores and detected issues.
5. Check recommendations.
6. Export reports as JSON or CSV.
